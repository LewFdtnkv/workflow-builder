# Flowcraft API {#mainpage}

Flowcraft — веб-приложение для визуального проектирования, сохранения и запуска workflow.
Эта документация описывает серверную часть на Spring Boot 3 и Java 21.

## Состав API

- `auth` — регистрация, вход, обновление токенов и выход;
- `workflow` — хранение графов, их проверка, запуск и история запусков;
- `config` — JWT-аутентификация, ограничение частоты запросов и CORS.

## Основные свойства

- API использует stateless JWT-аутентификацию: access token передаётся в заголовке
  `Authorization`, а refresh token хранится в HttpOnly cookie.
- Исполнитель workflow разрешает только публичные `http` и `https` адреса: localhost,
  private и link-local сети блокируются.
- Каждый запуск ограничен 100 шагами, а HTTP-узел — 30 секундами ожидания.

Результаты будут созданы в `docs/doxygen/output/html` и
`docs/doxygen/output/rtf`. Сгенерированные файлы исключены из Git, а исходные
комментарии, эта главная страница и конфигурация остаются версионируемыми.
